💬 Chat Message Flow
User types message + selects code
Frontend sends POST /v1/chat/message
Gateway validates JWT token
AI Service loads conversation history
Builds context: code + history + path
Calls Anthropic API (streaming)
Saves messages to PostgreSQL
Logs call to Langfuse
Streams tokens back via WebSocket
📄 File Open Flow
User clicks file in explorer
GET /v1/files/:workspace/:path
Gateway JWT check passes
File Service reads from FS or S3
Returns content + language + metadata
Monaco Editor loads content
Session Service updates tab state in Redis
🔐 Auth Flow
User clicks Login with GitHub
Redirect to GitHub OAuth
GitHub returns auth code
POST /v1/auth/github/callback
Auth Service exchanges code
Upserts user in PostgreSQL
Issues JWT (15min) + refresh (7d)
JWT in memory · refresh in httpOnly cookie
